# Terra Soar user guide

Terra Soar is a 3D globe and 2D map viewer for Windows and Linux. It shows
the Earth from NASA's Blue Marble imagery, shorelines, country outlines and
terrain built into the program, works fully offline, and adds layers from
web map servers (WMS, WMTS and XYZ tiles), features from web feature
services (WFS), KML files, satellites from their orbits, aircraft from
ADS-B, your own elevation files and web terrain services.

1. [Installing Terra Soar](installation.md): Windows, Linux, what the
   computer needs, where your files go.
2. [Getting around](getting-around.md): the globe and the map, the mouse
   and keyboard, the status bar.
3. [Layers and projects](layers.md): the layer list, collections, opacity,
   saving and opening projects.
4. [Adding WMS layers](adding-wms-layers.md): imagery and maps from web map
   servers.
5. [Adding WMTS layers](adding-wmts-layers.md): ready-made map tiles from
   web map tile servers: national base maps, satellite imagery.
6. [Adding XYZ tile layers](adding-xyz-layers.md): OpenStreetMap and other
   web maps served as `{z}/{x}/{y}` tiles.
7. [Adding WFS layers](adding-wfs-layers.md): points, lines and areas with
   their attributes from web feature services.
8. [KML and KMZ](kml.md): places, paths and areas from Google Earth and
   other programs.
9. [Terrain](terrain.md): relief, your own elevation files, web terrain,
   hillshade, the height readout, elevation profiles, sea level.
10. [Satellites](satellites.md): satellites from CelesTrak or TLE files,
    their tracks and passes, and the clock.
11. [Aircraft](aircraft.md): aircraft from ADS-B recordings and live
    receivers, their trails, playback and details.
12. [Using Terra Soar offline](offline-use.md): offline regions, data packs,
   disk space.

You can read this guide inside Terra Soar too, offline: **Help → User
Guide** (F1). F1 in a dialog opens the guide at the part about that
dialog. The window has the pages down the side, a search box that lists
the pages containing what you type, Back and Forward, and Ctrl+F to find
text on a page.

Help → About Terra Soar shows the version, the data in use with its
sources, licences and credits, and the licences of the libraries Terra
Soar is built on.
