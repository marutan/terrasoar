# Terra Soar user guide

Terra Soar is a 3D globe and 2D map viewer for Windows and Linux. It shows
the Earth from NASA's Blue Marble imagery, shorelines, country outlines and
terrain built into the program, works fully offline, and adds layers from
web map servers (WMS), your own elevation files and web terrain services.

1. [Installing Terra Soar](installation.md): Windows, Linux, what the
   computer needs, where your files go.
2. [Getting around](getting-around.md): the globe and the map, the mouse
   and keyboard, the status bar.
3. [Layers and projects](layers.md): the layer list, collections, opacity,
   saving and opening projects.
4. [Adding WMS layers](adding-wms-layers.md): imagery and maps from web map
   servers.
5. [Terrain](terrain.md): relief, your own elevation files, web terrain,
   hillshade, the height readout, elevation profiles, sea level.
6. [Using Terra Soar offline](offline-use.md): offline regions, data packs,
   disk space.

Help → About Terra Soar shows the version, the data in use with its
sources, licences and credits, and the licences of the libraries Terra
Soar is built on.
